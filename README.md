# Neer Vasa — Portfolio

Interactive portfolio featuring seven project entries and verified website, GitHub, release, and Chrome Web Store links.

## Run locally

```sh
python3 -m http.server 4173
```

Open http://localhost:4173. No build step or dependencies required.

## Publish

GitHub Pages serves the root of the `main` branch.

Project data and interactions: `app.js`. Layout: `index.html`. Styling: `style.css`.
